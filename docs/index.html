Astris UI

A clean, modern UI library for Roblox scripts. One line to load it, a few lines to build a full menu. This page walks you through it step by step.

Get started GitHub Example script
1

Load the library

Put this line at the very top of your script. It downloads Astris and gives you the Astris table you use for everything else.

local Astris = loadstring(game:HttpGet("https://raw.githubusercontent.com/OSSDiablo/Airflow-UI/main/Source.luau"))()
2

Make a window

The window is your menu. Give it a name and the key that hides it.

local Window = Astris:CreateWindow({
    Name = "My Hub",
    Subtitle = "v1.0",
    ToggleUIKeybind = "RightControl",
})

Run it and you already have a working menu with ready-made Server, ESP and Settings tabs, plus the round Astris button that hides and shows it.

Moving and resizing: drag any empty spot to move the menu. Drag the bottom-right corner to resize it.
3

Add a tab

Tabs are the buttons in the sidebar. Each one has its own page.

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Icon is any icon name from lucide.dev/icons, like "user", "sword" or "settings".

4

Add elements

Elements are the buttons, switches and sliders inside a tab. They all work the same way: a Name, and a Callback that runs when the user uses it.

Main:CreateSection("Player")

Main:CreateButton({
    Name = "Say hi",
    Callback = function()
        print("hi")
    end,
})

Main:CreateToggle({
    Name = "Auto sprint",
    Callback = function(Value)
        print("Auto sprint is", Value)
    end,
})

Every element is explained one by one further down this page.

5

Show a notification

A small card that pops up in the bottom-right corner and goes away on its own.

Astris:Notify({
    Title = "Loaded",
    Content = "Everything is ready",
    Type = "Success", -- "Info", "Success", "Warning" or "Error"
    Duration = 4,
})
6

Save the user's settings

Three things: turn saving on in the window, give each element a Flag (a unique name), and call LoadConfig at the very end.

local Window = Astris:CreateWindow({
    Name = "My Hub",
    ConfigurationSaving = { Enabled = true, FolderName = "MyHub" },
})

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Main:CreateToggle({
    Name = "Auto sprint",
    Flag = "AutoSprint",
    Callback = function(Value) end,
})

Window:LoadConfig() -- always last
Why last? Loading needs every element to exist first, so it knows where to put the saved values.

Button

Runs your code when clicked.

Main:CreateButton({
    Name = "Reset character",
    Desc = "Respawns you",       -- optional grey line
    Icon = "refresh-cw",         -- optional
    Style = "Danger",            -- optional: "Primary" or "Danger"
    Callback = function()
        game.Players.LocalPlayer.Character:BreakJoints()
    end,
})

Toggle

An on/off switch. The callback gets true or false.

Main:CreateToggle({
    Name = "Infinite jump",
    CurrentValue = false,        -- starts off
    Flag = "InfJump",
    Callback = function(Value)
        print(Value)
    end,
})

Slider

Pick a number between a min and a max. Users can also click the number to type one.

Main:CreateSlider({
    Name = "Walk speed",
    Range = { 16, 100 },         -- min, max
    Increment = 1,               -- step size
    Suffix = " sps",             -- optional text after the number
    CurrentValue = 16,
    Flag = "WalkSpeed",
    Callback = function(Value)
        print(Value)
    end,
})

Need plus and minus buttons instead? Use CreateStepper with the same options.

Dropdown

Pick one option from a list, or several with MultipleOptions = true.

local Mode = Main:CreateDropdown({
    Name = "Camera mode",
    Options = { "Classic", "Follow", "Orbital" },
    CurrentOption = "Classic",
    MultipleOptions = false,
    Flag = "CameraMode",
    Callback = function(Option)
        print(Option)
    end,
})

Mode:Refresh({ "Classic", "Follow" }) -- change the list later

Input

A text box. The callback runs when the user clicks away or presses Enter.

Main:CreateInput({
    Name = "Player name",
    PlaceholderText = "type here",
    Numeric = false,             -- true allows numbers only
    Callback = function(Text)
        print(Text)
    end,
})

Keybind

Lets the user pick a key. Your callback runs when they press it.

Main:CreateKeybind({
    Name = "Sprint",
    CurrentKeybind = "LeftShift",
    Mode = "Hold",               -- "Press" (default) or "Hold"
    Callback = function(Held)
        print("Sprinting:", Held)
    end,
})

Click the key chip, then press a new key to change it. Backspace clears it.

Color picker

Pick any colour. The callback gets a Color3.

Main:CreateColorPicker({
    Name = "ESP colour",
    Color = Color3.fromRGB(0, 227, 255),
    Flag = "EspColour",
    Callback = function(Color)
        print(Color)
    end,
})

Text and layout

Headings, lines and text to organise your tab.

Main:CreateSection("Movement")     -- heading
Main:CreateDivider()               -- thin line
Main:CreateLabel("Some grey text")
Main:CreateParagraph({
    Title = "About",
    Content = "Longer text that wraps onto more lines.",
})
Main:CreateProgress({ Name = "Loading", CurrentValue = 0.5 }) -- bar from 0 to 1

Change elements later

Every element gives you back a handle. Keep it in a variable to change the element from your code.

local Speed = Main:CreateSlider({ Name = "Walk speed", Range = { 16, 100 } })

Speed:Set(50)              -- change the value
print(Speed:Get())         -- read the value
Speed:SetTitle("Speed")    -- rename it
Speed:SetLocked(true)      -- lock it
Speed:SetVisible(false)    -- hide it
Speed:Destroy()            -- remove it

Want an element locked from the start? Add Locked = true and LockedReason = "Premium".

Built-in tabs

Astris comes with tabs you don't have to build yourself. They always sit at the bottom of the sidebar.

TabWhat it doesHow to turn it on or off
HomeGreeting and live stats: FPS, ping, time in the serverHome = true
ServerRejoin, server hop, join the smallest server, live server listServer = false to remove
ESPBoxes, names, distance, health, tracers, chams and outlines, with a live avatar preview beside the menuEsp = false to remove
SettingsTheme, hide key, saved configs, unload buttonSettings = false to remove
Astris:CreateWindow({
    Name = "My Hub",
    Home = true,
    Server = false,
})

Popups

Ask the user before doing something.

Astris:Confirm({
    Title = "Unload?",
    Content = "The menu will close.",
    ConfirmText = "Unload",
    Callback = function()
        Window:Destroy()
    end,
})

Need your own buttons? Use Astris:Dialog:

Astris:Dialog({
    Title = "Choose",
    Content = "Pick one.",
    Buttons = {
        { Title = "Later", Callback = function() end },
        { Title = "Now", Variant = "Primary", Callback = function() end },
    },
})

Themes

Six built in: Default, Midnight, Moss, Ember, Rose and Mono. Switching is instant, even while the menu is open.

Astris:SetTheme("Midnight")

-- or just change the accent colour
Astris:SetTheme({ Accent = Color3.fromRGB(0, 227, 255) })

Users can also pick a theme themselves in the Settings tab.

Window functions

CodeWhat it does

Full example

Copy this, run it, and change it into your own script.

local Astris = loadstring(game:HttpGet("https://raw.githubusercontent.com/OSSDiablo/Airflow-UI/main/Source.luau"))()

local Window = Astris:CreateWindow({
    Name = "My Hub",
    Subtitle = "v1.0",
    ConfigurationSaving = { Enabled = true, FolderName = "MyHub" },
})

local Main = Window:CreateTab({ Name = "Main", Icon = "zap" })

Main:CreateSection("Movement")

Main:CreateSlider({
    Name = "Walk speed",
    Range = { 16, 100 },
    CurrentValue = 16,
    Flag = "WalkSpeed",
    Callback = function(Value)
        local Character = game.Players.LocalPlayer.Character
        local Humanoid = Character and Character:FindFirstChildOfClass("Humanoid")
        if Humanoid then
            Humanoid.WalkSpeed = Value
        end
    end,
})

Main:CreateToggle({
    Name = "Infinite jump",
    Flag = "InfJump",
    Callback = function(Value)
        print("Infinite jump", Value)
    end,
})

Main:CreateButton({
    Name = "Reset character",
    Style = "Danger",
    Callback = function()
        game.Players.LocalPlayer.Character:BreakJoints()
    end,
})

Astris:Notify({ Title = "My Hub", Content = "Loaded", Type = "Success" })

Window:LoadConfig()
